## 背景

活动临近，需要给 300 张参与者 NFC 卡录入 token，并确保活动期间 token 不会被意外改写。本阶段补齐三处缺口：批量生成脚本、后台批量操作、token 锁定保护。

## 一、参与者卡批量生成 & 本地备份

### 新增脚本 `server/scripts/generate-cards.js`

| 模式 | 命令 | 效果 |
|------|------|------|
| 生成 | `npm run cards:generate -- --count 300` | 在 DB 插入 300 张空白卡，输出 `local/nfc-cards.csv` |
| 恢复 | `npm run cards:import -- local/nfc-cards.csv` | 从备份 CSV 还原同一批 token（幂等） |

**CSV 格式** (`local/nfc-cards.csv`)：
```
index,nfc_token,login_url
1,20b131d5-...,18trip.tyzhome.xyz/?nfc=20b131d5-...
```
- `login_url` 已去掉 `https://`，直接用于 NFC Tools 写卡
- 文件存入 `local/`（已加入 `.gitignore`，永不进 git）
- **防覆盖保护**：文件已存在时拒绝生成，需 `--force` 或换 `--out` 路径

### 新增脚本 `server/scripts/export-spot-tokens.js`

```bash
npm run cards:export-spots
```

输出 `local/spot-tokens.csv`，含 19 个打卡点的 token 与写卡 URL，用于现场写卡核对。

**CSV 格式**：
```
display_order,type,name,spot_token,spot_url
1,venue,朝班,a0000000-0000-0000-0000-000000000001,18trip.tyzhome.xyz/?spot=a0000...
```

## 二、后台批量操作（AdminUsers）

### 多选功能

- 表格最左侧新增复选框列，含表头「全选」（仅选当前页）
- Admin 行与已停用行的复选框置灰不可选
- 搜索 / 刷新后自动清空选中

### 批量操作栏

选中 ≥ 1 行时工具栏下方出现操作栏，含两个批量操作：

| 操作 | 端点 | 效果 |
|------|------|------|
| 仅清空注册信息 | `POST /api/admin/users/clear-registration` | 清空 username/password/city，is_registered=false；**保留打卡记录与 token** |
| 完全重置为新卡 | `POST /api/admin/users/reset-card` | 同上 + 删除打卡记录；**保留 token** |

防误触设计：弹窗中「取消」按钮为醒目绿色（主色），「确认」按钮为低调灰色描边，需刻意点击才能执行。

## 三、Token 锁定保护

### 挂失换卡（重写）

**原实现**：挂失 = `UPDATE users SET nfc_token = gen_random_uuid()`（改写 token）

**新实现**：挂失 = 停用源卡 + 把注册信息 & 打卡记录迁移到指定的空白备用卡（**token 全程不变**）

操作流程：
1. 参与者卡丢失 → 后台点「挂失」
2. 在弹窗输入**目标空白卡的 user id**（备用卡）
3. 执行后：旧卡停用，身份与打卡无缝转移到新卡

后端校验：
- 目标卡必须为空白未注册卡，否则 409
- 缺少 `targetUserId` → 400
- 整个迁移在事务内执行，失败自动回滚

### `db:reset` 生产环境守卫

新增 `server/scripts/db-reset-guard.js`，在 `db:reset` 前自动执行：

```bash
# 生产环境直接拒绝
NODE_ENV=production npm run db:reset
# → 已拦截：...如确需执行：DB_RESET_FORCE=1 npm run db:reset

# 显式强制才放行
NODE_ENV=production DB_RESET_FORCE=1 npm run db:reset
```

### `cards:generate` 防覆盖

已有备份文件时拒绝生成：

```bash
npm run cards:generate  # local/nfc-cards.csv 已存在 → 拒绝
npm run cards:generate -- --force  # 强制覆盖
npm run cards:generate -- --out local/nfc-cards-v2.csv  # 换路径
```

## 四、本地测试 & iOS NFC 说明

### 局域网测试

Vite 已配置 `host: '0.0.0.0'`，无需改动。手机与 Mac 同一 Wi-Fi 后：

- 前端访问：`http://192.168.x.x:5173/`
- NFC 写入 URL：`http://192.168.x.x:5173/?nfc=<token>`

### iOS NFC 限制

iOS NFC 后台自动识别仅对 **HTTPS** 链接生效。本地测试使用 ngrok：

```bash
ngrok http 5174  # 获取 https://xxxx.ngrok-free.dev
# 写卡 URL 改为 https://xxxx.ngrok-free.dev/?nfc=<token>
```

Vite 已配置放行所有 ngrok 子域名（`allowedHosts`），每次启动无需修改配置。

部署到 `https://18trip.tyzhome.xyz` 后 iOS 完全正常。
