# v0.2 — 成就列表 + 地图 + 场馆图

**分支：** `dev-v0.2-glm`  
**合并日期：** 2026-05-25  
**基于：** v0.1（Phase 1-3 完成后）

---

## 核心改造

### 数据模型扩展

`check_in_spots` 新增字段，支持场地与 NPC 两种打卡点类型：

| 字段 | 说明 |
|------|------|
| `type` | `venue`（场地）/ `npc`（区长） |
| `description` | 成就列表解锁后展示的文案 |
| `activity_intro` | NPC 活动简介（楼层列表使用） |
| `floor` | NPC 所在楼层（1-4） |
| `pos_x / pos_y` | NPC 在楼层图上的坐标百分比 |

打卡点从 6 个扩展至 **18 个**（4 场地 + 10 NPC + 4 其他成就）。

### 成就系统重设计

- **Profile 页** 从 6 格成就墙改为按类型分段的纵向成就列表
- 新增 `AchievementListItem` 组件（左图标 + 右文案，locked/unlocked 状态）
- 服务端对未解锁 spot 的 `description` 进行遮蔽（返回空字符串）
- **计划通**成就：打满 14 个 base 点（4 venue + 10 NPC）后服务端自动解锁，无需 NFC

### 地图系统

新增路由 `/map`，两个入口：

- `/map/changsha` — 长沙城市地图（当前为"敬请期待"占位页）
- `/map/venue` — 四层伪 3D 场馆图

### 场馆图（`/map/venue`）

- `FloorStack` 组件：电梯式纵向层叠，点击楼层切换 + 3D 倾斜动效
- 支持上下滑动手势切换楼层
- 楼层平面图上显示 NPC 图标标注，点击跳转 NPC 详情页
- 底部联动列表按楼层过滤 NPC，点击跳转详情

### NPC 详情页（`/npc/:id`）

展示区长头像、日文名、活动介绍、班次归属。

### NPC 头像资源

- 10 张 NPC 头像置于 `public/npc/`（`npc_kafka.png` 等）
- 组件通过 `asset_key` 动态拼接路径 `/npc/{asset_key}.png`，兜底回退至 `/shumai.png`
