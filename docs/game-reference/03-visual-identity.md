# 18TRIP 视觉识别参考

> **用途**：本项目（活动站 PWA）视觉系统的官方对齐参考
> **信息时点**：2026-05
> **来源**：所有 HEX 来自 [wiki.18t.rip](https://wiki.18t.rip) 各角色页 infobox 的 `Image Color` 字段（社区维护，与官方卡面/MV 配色一致）

---

## 1. 品牌核心

| 项目 | 说明 |
|------|------|
| 品牌名 | **18TRIP**（エイティーントリップ） |
| Logo | "18TRIP" 字样设计，"1" 与 "8" 中常带轨道/数字电路风格的装饰元素 |
| 主色（推测） | ⚠估算 **#FFFFFF 白底 + #000000 黑字**（官方 KV 多采用极简底色 + 角色撞色） |
| 强调色 | 横滨 / 旅游 / 偶像 三大语义混合，统一通过"时段"色温体现 |

> 18TRIP 没有强势的"单一品牌色"。**真正承载品牌识别的是「四组×时段」的色温体系**（早/午/暮/夜），以及每位区长的个人主题色。

---

## 2. 视觉调性关键词

- **时段感（晨/午/暮/夜）**：4 组色温梯度是品牌最强识别
- **数字化偶像**：组合名 R**1**ze / Day**2** / Ev**3**ns / L**4**mps 都用数字替字母，呼应电子标签风
- **旅行/票据**：HAMA TOURS 的视觉常借车票、行李吊牌、地图、邮戳元素
- **青春群像**：Day2 高中部分明亮可爱，Ev3ns 反叛撞色，R1ze 通透浪漫，L4mps 霓虹深夜
- **近未来横滨**：港口、高架、霓虹、海湾，整体偏 Y2K + 城市流行

---

## 3. 班级（组合）主题色

色温从早到晚，整体呈现"暖橙金 → 翠绿/粉 → 紫绿撞色 → 深紫霓虹"的一日推移。下表为各组的"主色调方向 + Conductor 的色彩定位"。

### R1ze（朝班 Morning）

| 项目 | 内容 |
|------|------|
| 关键词 | 晨光、金黄、通透蓝、浪漫起航 |
| 色相方向 | 金黄（队长 Renga #DCAA3C）+ 通透蓝（#46BEFF）+ 柔紫（#A58CFF） |
| 反差色 | 鹿礼光的赤红 #FF3214 是组内"危险/外来者"标识 |
| 推荐组合主色 | ⚠估算 **#F4C45B**（暖金 - 取 Renga 与 Yukikaze 中间偏暖） |

### Day2（昼班 Noon）

| 项目 | 内容 |
|------|------|
| 关键词 | 高饱和、青春、糖果、校园 |
| 色相方向 | 暖橙（队长 Akuta #FF8232）+ 青柠 #96F032 + 紫罗兰 #AF5AE6 + 樱粉 #FFA5D2 + 青绿 #37C3B9 |
| 整体感 | 撞色饱和但偏明亮，5 人各占一色 |
| 推荐组合主色 | **#FF8232**（直接采用队长色，已是组合最强识别） |

### Ev3ns（夕班 Evening）

| 项目 | 内容 |
|------|------|
| 关键词 | 夕焼、反叛、撞色、玫瑰金、低饱和暗调 |
| 色相方向 | 墨绿（队长 Raito #41916E）+ 玫红 #DC376E + 翠绿 #46EB9B + 浅紫 #EBC8FF + 雾蓝 #5A9BC8 |
| 整体感 | 反主流配色，对比强烈，带"出狱后的不羁感" |
| 推荐组合主色 | ⚠估算 **#DC376E**（玫红 - 比队长墨绿更具张力，是组合 MV 的高频用色） |

### L4mps（夜班 Night）

| 项目 | 内容 |
|------|------|
| 关键词 | 霓虹、深夜、灯火、迷离 |
| 色相方向 | 靛紫（队长 Nagi #736EEB）+ 玫粉 #FF507D + 蜜黄 #FFDC64 / #F0E6AA + 樱花粉 #FF32C8 |
| 整体感 | 深底 + 高饱和点光，最接近"夜店霓虹"调 |
| 推荐组合主色 | **#736EEB**（靛紫 - 队长色，氛围最契合"夜"主题） |

### kfk（项目专属：Kafka & Shumai）

| 项目 | 内容 |
|------|------|
| 关键词 | 故事核心、紫调、双主理人 |
| 色相方向 | Kafka 主色 **#A58CFF**（淡紫）+ Shumai 推测为暖白米黄 |
| 推荐组合主色 | **#A58CFF**（采用 Kafka 主色） |

## 5. 字体与排版

> 官方字体未在 wiki 直接列出，以下基于游戏 KV/MV 视觉风格的合理推断。

| 用途 | 日文字体推断 | 拉丁字体推断 | 中文替代方案 |
|------|------------|------------|-------------|
| Logo / 标题 | 自制字形（带几何修饰） | Druk / Migra / Mona Sans 等 Display sans | 思源黑体 Heavy / OPPO Sans Heavy |
| 副标题 | TT-Shin Go / 平成角ゴ | Inter / DM Sans | 思源黑体 Medium / HarmonyOS Sans |
| 正文 | Hiragino Sans / Noto Sans JP | Inter | 思源黑体 / 思源宋体（强情感场景） |
| 数字 / 票据 | OCR-B / 等宽 | JetBrains Mono / IBM Plex Mono | 同左 |

**层级建议**：
- H1 / 主标题：≥ 28px，800 字重，搭配组合主题色
- H2 / 区段：20–22px，600 字重
- 正文：14–16px，400 字重，line-height 1.6
- 数字（票号、打卡时间）：等宽，略小字号

## 6. 视觉元素与图形语言

| 元素 | 出处 / 用法 |
|------|------------|
| **车票 / 行李吊牌** | HAMA TOURS 的核心隐喻，可用于打卡凭证、成就徽章背景 |
| **邮戳 / 印章** | 模拟旅游打卡章，适合"集齐图纸"的成就墙 |
| **地图 / 路径线** | HAMA-18 区域图，可在首页 / Hero 区做装饰 |
| **数字徽章** | 组合名替字风（1/2/3/4）可延展到本站的 5 个时间段 / 5 个打卡点编号 |
| **撞色 Pattern** | Ev3ns / L4mps 大量使用对角条纹、撞色块 |
| **霓虹光晕** | L4mps 夜班场景常见，可用于打卡成功的高光动效 |

**插画/摄影风格**：偏 Y2K 现代日漫 + 平面海报。立绘以高对比、强光影、撞色背景为主。Chibi 风（即本项目素材所用）走 Q 版 SD 头身，色块平面、轮廓干净。

## 7. 推荐 CSS 变量映射

可直接落到 `src/styles/` 或 Tailwind theme，作为本活动站设计系统的色彩基线。

```css
:root {
  /* === 品牌基底 === */
  --brand-bg: #FFFFFF;
  --brand-fg: #111111;
  --brand-accent: #A58CFF;          /* 沿用 Kafka 主色作活动站主调 */

  /* === 4 组 + kfk 主题色 === */
  --group-morning: #F4C45B;          /* R1ze 朝班（⚠估算综合色） */
  --group-noon:    #FF8232;          /* Day2 昼班（队长 Akuta） */
  --group-evening: #DC376E;          /* Ev3ns 夕班（⚠估算综合色） */
  --group-night:   #736EEB;          /* L4mps 夜班（队长 Nagi） */
  --group-kfk:     #A58CFF;          /* Kafka & Shumai */

  /* === 状态色 === */
  --state-locked:    #C9C9C9;        /* 成就墙未解锁 */
  --state-unlocked:  var(--brand-accent);
  --state-highlight: #FFD84D;        /* 打卡 pulse 动画黄 */

  /* === 中性灰阶 === */
  --gray-50:  #FAFAFA;
  --gray-100: #F2F2F2;
  --gray-300: #D4D4D4;
  --gray-500: #8A8A8A;
  --gray-700: #404040;
  --gray-900: #1A1A1A;

  /* === 排版基线 === */
  --font-display: "Inter", "PingFang SC", "Hiragino Sans", system-ui, sans-serif;
  --font-body:    "Inter", "PingFang SC", system-ui, sans-serif;
  --font-mono:    "JetBrains Mono", "SF Mono", Menlo, monospace;
}
```

**用法约定**：
- 打卡点徽章：根据该点位的"班级归属"用 `--group-*` 渲染描边/背景
- 成就墙锁定槽：`--state-locked`；解锁后用对应 `--group-*` 染色
- 打卡成功 pulse：从 `--state-highlight` 渐变到 `--group-*`
- 全局 CTA（登录/确认）：`--brand-accent`
